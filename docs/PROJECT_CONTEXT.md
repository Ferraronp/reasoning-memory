# Контекст проекта

Основная гипотеза Артура: представление собственного прошлого модели как компактных,
повторно используемых результатов может улучшить решение задач, требующих объединения
ранее полученных результатов. Мотивация — уменьшение расстояний и количества подробного
текста между ними. Механизм attention отдельно доказывать на первом этапе не требуется.

Всё происходит внутри одного think. Модель открывает эксперимент, завершает его и
пишет вывод. После каждого вывода система ОБЯЗАТЕЛЬНО удаляет эксперимент из активного
контекста и перестраивает затронутый cache. Отдельного решения «что удалять» нет.
Полный эксперимент хранится под ID и может быть выборочно восстановлен.
Summary переносит информацию текстом; скрытого переноса через старый KV быть не должно.

Цель — качество, не преимущественно память/ускорение. ARC-AGI не выбран; речь о сложном
рассуждении в целом. Вложенность отложена. Новизна не подтверждена, ближайшую литературу
нужно отдельно перепроверить перед научными утверждениями.

Ресурсы: у пользователя есть GTX 1660 Super, предполагаемая площадка — Google Colab T4.
Маленькая модель нужна для первоначальной отладки. Предпочтение для основных тестов —
около 9B, вероятно INT8. Начальные технические прогоны — 16-битные веса без квантизации.
Загрузка 9B FP16 на T4 не планируется. Длина контекста и память определяются измерением.

Код хранится в .py, ноутбук служит точкой запуска. GitHub-репозиторий:
https://github.com/Ferraronp/reasoning-memory (private). Первая ячейка Colab
клонирует/обновляет main без перезаписи локальных правок. Других агентов
пользователь, возможно, подключит позднее; данная версия сделана без делегирования.

но не выдала experiment/summary-теги; свёртка не выполнялась. Исправлена отчётность:
такой исход — один сбой общего префикса, а не два провала сравниваемых политик.
Добавлен guided_single с границами, задаваемыми контроллером, как отдельный
технический тест. Самостоятельный выбор границ остаётся целью автономного режима.
Результата о пользе забывания пока нет.
